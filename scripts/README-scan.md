# Поиск белых подсетей VK из-под своей SIM

`white-subnet-scan.py` отвечает на вопрос «какие подсети VK доходят через
моего оператора в зоне белых списков». Запускать **на телефоне в Termux**,
под целевой SIM, **с выключенным Wi-Fi** — иначе проверяется не тот канал.

## Termux

```bash
pkg install python
python white-subnet-scan.py --asn 47764 --only-alive
```

`--asn 47764` тянет все префиксы, которые VK анонсирует в BGP, из публичного
RIPEstat. Можно указать несколько `--asn` (у VK не один номер) или дать свой
список:

```bash
python white-subnet-scan.py --file subnets.txt          # по CIDR в строке
python white-subnet-scan.py 217.16.16.0/20 5.188.140.0/22
```

## Что делает

Берёт по 3 случайных адреса из каждой подсети и проверяет достижимость:
ICMP-пинг плюс TCP-коннект на 443 и 80. Подсети, откуда что-то ответило,
поднимаются наверх и помечаются 🎯:

```
🎯 217.16.16.0/20       2/3  217.16.28.62(tcp:443,80)  217.16.19.4(icmp)
   161.104.104.0/22     0/3
```

## Важные оговорки

- **ICMP часто режется** фаерволом облака, поэтому и добавлен TCP. «Молчит»
  ≠ «не белая»: адрес может быть незанят или хост не отвечает на пробы.
- Это **предварительный фильтр канала**, а не доказательство. Он показывает,
  куда оператор пускает трафик, но финальную пригодность конкретного адреса
  подтверждает только реальный запрос на вашу ВМ с этим IP через ту же SIM.
- Проверяется несколько адресов на подсеть, без нагрузки: это тест
  маршрута, а не перебор хостов.

## Как этим пользоваться с ботом

1. Скрипт покажет подсети с 🎯 — куда ваш оператор пускает.
2. Их CIDR добавьте в цели бота: `/targets 217.16.16.0/20, …`
3. `/subnets` → отметьте подсети, которые проект реально отдаёт
   (`/availability` покажет, у каких `total > 0`).
4. `/hunt` — и бот ловит адрес именно в достижимом пуле.
